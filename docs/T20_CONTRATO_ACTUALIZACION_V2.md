## 2. Existencia reconstruida (`pipeline/inventory/reconstructed.py`, responsable: datos)
Paquete (carpeta): `existencias.csv` + `manifest.json` (lo genera `scripts/sql21_prepare.py`).
- `existencias.csv` (50 filas, cantidades enteras): `producto_id` (código original sin ceros), `producto`, `unidad_reporte`, `unidad_descripcion`, `conteo_libre`, `entradas_hasta_cierre`, `salidas_hasta_cierre`, `existencia_cierre_20_10`, `entradas_hasta_ultimo_mov`, `salidas_hasta_ultimo_mov`, `existencia_ultimo_mov`, `stock_sistema_ultimo_mov`, `reservado_sistema`, `diferencia`, `estado` (`COINCIDE`|`DISCREPANTE`).
- Reglas verificadas al importar: `existencia_cierre = conteo + entradas_cierre − salidas_cierre`; `existencia_ultimo_mov = conteo + entradas_ult − salidas_ult`; `diferencia = stock_sistema_ultimo_mov − existencia_ultimo_mov`; `estado = COINCIDE` ⇔ `diferencia == 0`; existencias no negativas; el conjunto de productos y el `conteo_libre` coinciden con el snapshot T18 base (si existe en la base); el SHA-256 del CSV coincide con el manifiesto. **La comparación con el stock del sistema se hace en la misma fecha (último movimiento); el stock base del plan es el de cierre 20/10.**
- `manifest.json`: `kind: "EXISTENCIA_RECONSTRUIDA"`, `warehouse {id:"1", name}`, `as_of_local: "2026-10-20T23:59:59-05:00"`, `base_count {snapshot_id, as_of_local: "2026-10-18T17:00:00-05:00", csv_sha256}`, `movements {from_local, closing_local, last_movement_local: "2026-10-21T16:26:38-05:00"}`, `rule` (texto), `csv_sha256`, `sql_report_sha256`, `generated_at`. El respaldo no tiene hora conocida: `last_movement_local` es la hora de la última operación.
- Colecciones nuevas `inventory_reconstructed_snapshots` / `inventory_reconstructed_items` (no se tocan `inventory_reported_*`). `snapshot_id = invrec-20261020-<sha12>`; cabecera con `kind`, `version`, `status` (staging→current), `supersedes`, `as_of_local`, `as_of_utc`, `warehouse`, `source {sha256, csv_sha256}` (para la identidad del plan), `base_count`, `movements`, `counts {products, discrepancies}`, `rule`. Ítem: `producto_id, producto, categoria, unidad_reporte, unidad_descripcion, libre` (= `existencia_cierre_20_10`), `base_count`, `movements {entradas_cierre, salidas_cierre, entradas_ultimo_mov, salidas_ultimo_mov}`, `reconstructed_at_last_movement`, `system_stock_at_last_movement`, `system_reserved`, `discrepancy: null | {difference, compared_at_local}`.
